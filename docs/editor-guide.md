# Cursor エディターの使い方まとめ

## 基本操作

### ファイル・フォルダ
| 操作 | 方法 |
|------|------|
| ファイルを開く | `Cmd + P`（Mac）/ `Ctrl + P`（Win）→ ファイル名を入力 |
| フォルダを開く | メニュー「File」→「Open Folder」 |
| ファイルを保存 | `Cmd + S` / `Ctrl + S` |
| すべて保存 | `Cmd + K S` / `Ctrl + K S` |
| タブを閉じる | `Cmd + W` / `Ctrl + W` |

### 編集
| 操作 | 方法 |
|------|------|
| 元に戻す | `Cmd + Z` / `Ctrl + Z` |
| やり直し | `Cmd + Shift + Z` / `Ctrl + Shift + Z` |
| 行をコピー | 行にカーソル → `Cmd + C`（何も選択していない場合） |
| 行を切り取り | 行にカーソル → `Cmd + X` |
| 行を下に複製 | `Shift + Alt + ↓` / `Shift + Alt + Down` |
| 行を上に移動 | `Alt + ↑` / `Alt + Up` |
| 行を下に移動 | `Alt + ↓` / `Alt + Down` |
| 複数行を一括編集 | 同じ単語で `Cmd + D` を繰り返し → 複数カーソル |

### 検索・置換
| 操作 | 方法 |
|------|------|
| ファイル内検索 | `Cmd + F` / `Ctrl + F` |
| 置換 | `Cmd + H` / `Ctrl + H` |
| プロジェクト全体検索 | `Cmd + Shift + F` / `Ctrl + Shift + F` |
| シンボル（関数・クラス等）検索 | `Cmd + T` / `Ctrl + T` |

---

## ナビゲーション

| 操作 | 方法 |
|------|------|
| 行番号へジャンプ | `Cmd + G` / `Ctrl + G` → 行番号入力 |
| 定義へジャンプ | シンボルにカーソル → `F12` または `Cmd + クリック` |
| 参照を検索 | シンボルにカーソル → `Shift + F12` |
| 前に戻る | `Alt + ←` / `Ctrl + Alt + -` |
| 次に進む | `Alt + →` / `Ctrl + Shift + -` |
| サイドバー（エクスプローラー） | `Cmd + B` / `Ctrl + B` |
| コマンドパレット | `Cmd + Shift + P` / `Ctrl + Shift + P` |

---

## 画面レイアウト

| 操作 | 方法 |
|------|------|
| エディターを分割 | `Cmd + \` / `Ctrl + \` |
| 分割ペイン間を移動 | `Cmd + 1` `Cmd + 2` … または `Ctrl + 1` … |
| ターミナルを開く | `` Cmd + ` `` / `` Ctrl + ` `` |
| ターミナルの表示切替 | `` Cmd + Shift + ` `` |

---

## Cursor 固有（AI）

| 操作 | 方法 |
|------|------|
| AI チャットを開く | `Cmd + L` / `Ctrl + L` |
| インライン編集（コード内で AI に聞く） | 選択して `Cmd + K` / `Ctrl + K` |
| コンテキストにファイルを追加 | チャットで `@` と入力 → ファイル名やフォルダを選択 |

---

## よく使うショートカット（開発向け）

| 操作 | 方法 |
|------|------|
| クイックオープン（ファイル） | `Cmd + P` |
| コマンド実行 | `Cmd + Shift + P` |
| 問題（エラー・警告）パネル | `Cmd + Shift + M` |
| 次の問題へ | `F8` |
| フォーマット | `Shift + Alt + F`（多くの言語） |
| リネームシンボル | シンボルにカーソル → `F2` |
| コメントアウト | `Cmd + /` / `Ctrl + /` |
| ブロックコメント | `Shift + Alt + A` |

---

## 設定の場所

- **ユーザー設定**: `Cmd + ,` → 設定画面  
- **キーバインド**: `Cmd + K Cmd + S` → キーボードショートカット  
- **設定 JSON**: コマンドパレットで「Preferences: Open User Settings (JSON)」

---

## ヒント

1. **コマンドパレット**（`Cmd + Shift + P`）でやりたい操作を検索すると、多くの機能にアクセスできます。
2. **ファイル名の横**に「U」や「M」などが出ている場合は Git の状態（未追跡・変更）です。
3. **左サイドバー**のアイコンで、エクスプローラー・検索・Git・デバッグなどに切り替えられます。
