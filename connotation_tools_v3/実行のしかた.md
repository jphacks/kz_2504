# connotation_tools_v3 ターミナルでの実行のしかた

このフォルダ（`connotation_tools_v3`）のコードを**ターミナルで実行する方法**だけまとめます。

---

## 事前準備（1回だけ）

Mac では `pip` が使えない／システム Python に直接入れられないことがあるので、**仮想環境（venv）** を使います。

```bash
cd connotation_tools_v3
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements_gemini.txt
```

- いちど **`source .venv/bin/activate`** すると、そのターミナルでは `python` / `pip` が venv のものになります。
- **Gemini API キー**: 環境変数 `GEMINI_API_KEY` を設定するか、解析用スクリプト内の `HARD_CODED_GEMINI_API_KEY` にキーを書く。
- 動画ファイルは **`videos/`** に置く（例: `videos/my_video.mp4`）。

---

## 1. 解析（動画 → タイムライン JSON）

```bash
cd connotation_tools_v3
python analyze_video_gemini.py my_video.mp4
```

- 動画は `videos/` 内ならファイル名だけでよい。フルパスでも可。
- 出力: `results/my_video_timeline.json`

---

## 2. 再生（動画 + JSON で効果付き再生）

```bash
cd connotation_tools_v3
python playback_video.py my_video.mp4
```

- 使う JSON: `results/my_video_timeline.json` または `editor_results/my_video_timeline.json`（あればこちら優先）。
- 別の JSON を指定する場合:
  ```bash
  python playback_video.py my_video.mp4 editor_results/別名_timeline.json
  ```

**操作**: スペース＝一時停止、R＝最初から、Q＝終了

---

## 3. タイムラインエディタ（GUI）

**エディタでタイムライン JSON を手動で作りたいとき**はこちら。

```bash
cd connotation_tools_v3
source .venv/bin/activate
pip install PyQt6 librosa moviepy   # 初回だけ
python timeline_editor_v3.py 動画ファイル名.mp4
```

- 保存先 JSON 名を聞かれたら入力（空 Enter で `editor_results/動画名_timeline.json`）。
- エディタで効果を打ち込んで保存したあと、再生は `python playback_video.py 動画ファイル名.mp4` でOK（`editor_results/` の JSON が自動で使われる）。

---

## 4. 研究用（エディタ JSON からプロンプト再生成）

```bash
cd connotation_tools_v3
python research_prompt_from_editor.py my_video.mp4
```

オプション例:

```bash
python research_prompt_from_editor.py my_video.mp4 --json editor_results/my_video_timeline.json --max-frames 120
```

- 出力: `research_outputs/` に保存。

---

## 一覧

|--------------|----------|

| 再生 | `python playback_video.py my_video.mp4` |

| 研究（プロンプト再生成） | `python research_prompt_from_editor.py my_video.mp4` |

いずれも **`connotation_tools_v3` に cd してから**実行してください。
